# Guarded task, menu and Dock integration

Prepared November 3. Not yet qualified on the actual Mac. The earlier fixed-public pair passed on Mac; this own-notes form, Save Copy and app bundle are new and need their own check.

The app keeps its menu-bar icon and adds a named user-local MuseSwarm.app launcher with running Dock presence. Reopening from Dock shows Guarded task. Existing Status, Safety check, Activity and Workspace remain available. It installs no dependencies, system hooks or background login item. Keep in Dock is a normal user action; no Dock preferences are rewritten.

User flow: paste up to1KiB of public/non-sensitive notes, type a goal up to512bytes, Review exact notes and disclosure/billing boundaries, then choose separate Start once. Meta proposes one artifact, both defenders must allow that exact action before creation, and worker stop/removal must verify before Save Copy. Failure or veto withholds output. Save Copy opens the native location chooser and never silently overwrites an existing file. Technical stop reasons are behind Details, not mixed into a successful draft.

This is a usable scoped defender demonstration, not a substitute claim for the broader whole-computer goal. No other app or agent is protected. The user supplies their own existing Meta key and OrbStack environment. First-time onboarding and distribution are not solved by an unsigned local launcher. Secret checks are limited; private text must not be inferred into a testing grant. Real disclosure and credit use require the owner's reviewed task authority.
