# Staged native task candidate

This is a working-flow candidate for Mac qualification, not a released or verified native product. It does not enable the older paid buttons. It does not protect arbitrary agents or the whole Mac.

Launch: `./run_staged_product.sh` from the existing checkout. Launch only displays review. It installs nothing and makes no model request. Use only after current promotional credit is verified under the owner's existing test-credit authority. There is no hard dollar cap and no card-overage authority.

The separate Start runs a fixed public launch-note task through the actual task model and two defender roles, bounded to three requests. Only one checklist artifact is accepted. Then a separate fixed worker deliberately proposes a harmful output, reviewed by the real defenders, bounded to two requests. That counterpart is an injected proposal, not a spontaneous attack or a task-model-generated attack. Grounded veto, no artifact, actual owned-worker stop and removal are required. The panel shows useful output and blocked counterpart, with public-fixture evidence saved locally. No project files are changed, exported automatically or uploaded beyond the fixed public note/proposals to Meta. At most five requests,8000 completion tokens including reasoning, bounded input,low effort,no retries.
